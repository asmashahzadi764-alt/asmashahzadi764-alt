# 👩‍💻 About Me

Hi! I'm **Asma Shahzadi**, a **BS Information Technology (BSIT)** student from Pakistan with a strong interest in **Frontend Development** and modern web technologies.

I enjoy transforming ideas into responsive, user-friendly web applications while continuously improving my problem-solving and development skills through hands-on practice.

Over the past few months, I have built multiple practice projects covering **HTML, CSS, JavaScript, Django, Git, GitHub, and React fundamentals**, helping me strengthen both my programming concepts and project development experience.

I'm passionate about continuous learning and enjoy exploring new technologies by building real-world projects rather than just reading documentation.
